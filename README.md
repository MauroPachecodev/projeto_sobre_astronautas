# projeto_sobre_astronautas
Para rodar este projeto, você precisa ter um compilador C++ (como o GCC/g++) instalado no seu sistema.
1. No Windows

Se você utiliza o MinGW, MSYS2 ou o terminal do VS Code:
    Abra o prompt de comando ou PowerShell na pasta do projeto.

    Compile todos os arquivos executando:
    g++ *.cpp -o sistema.exe

    Execute o programa:
    ./sistema.exe

2. No Linux ou macOS

    Abra o terminal na pasta onde os arquivos foram extraídos.

    Compile o projeto:
    g++ *.cpp -o sistema

    Dê permissão de execução (se necessário):
    chmod +x sistema

    Execute o programa:
    ./sistema
